# MonkeyTUI for Arch Linux

A Monkeytype-inspired terminal typing application.

## Installation

```bash
git clone https://github.com/harshrajsachan/monkeytui-arch.git
cd monkeytui-arch
makepkg -si
```

## Run

```bash
monkeytui
```

## Uninstall

```bash
sudo pacman -Rns monkeytui
```

## Requirements

- Arch Linux
- Java Runtime 17 or newer
